<a name="features"></a>
## ✨ Features & Capabilities

- 🤖 **AI-Powered 7-Day Content Roadmap**: Generates a synchronized week-long content calendar customized to your brand's voice, niche, and strategic growth goals.
- 🎯 **Multi-Platform Native Optimization**:
  - 📸 **Instagram**: Visual hooks, reels suggestions, carousel storytelling, and curated hashtag clusters (5–8 tags).
  - 💼 **LinkedIn**: Thought-leadership narratives, professional case studies, and career advice formats.
  - 🐦 **X (Twitter)**: High-velocity threads, punchy conversational prompts, and poll ideas.
  - 👥 **Facebook**: Community engagement questions, video discussions, and group sharing prompts.
  - 📌 **Pinterest**: Visual search keywords, step-by-step guides, and aesthetic product showcases.
  - ▶️ **YouTube**: Shorts ideas, title hooks, thumbnail concepts, and description copy.
- ⚡ **1-Click Sample Brand Presets**: Instant autofill for 6 diverse industries:
  - 🏋️ *FitLife* (Fitness & Wellness)
  - 🌿 *EcoSphere Tech* (Sustainable Clean Tech & SaaS)
  - ☕ *Bean & Brew* (Artisanal Café & Food)
  - 🧴 *LuxeGlow Skincare* (Beauty & Clean Skincare)
  - 💻 *CodeCraft Academy* (EdTech & Coding Bootcamps)
  - 🏡 *UrbanNest Realty* (Real Estate & Interior Architecture)
- 🔄 **Individual Post Regeneration**: Regenerate any specific day's caption and hashtags with a single click without re-generating the entire week.
- 📅 **Interactive Calendar & Kanban Views**: Switch between day cards and visual calendar grids with peak-hour posting indicators.
- 📤 **Multi-Format Export Engine**:
  - 📋 **Copy to Clipboard**: Quick copy formatted per day or entire schedule.
  - 📝 **Markdown (.md)**: Clean structured export ready for Notion, Obsidian, or GitHub.
  - 📄 **Print & PDF Presentation Report**: Formatted client-ready deliverables.
- 📖 **Built-in Documentation Hub**: Integrated modal with in-depth platform strategies, best practices, and contribution guides.

<a name="installation"></a>
## 🚀 Installation & Setup

> 💡 **Try it Live Without Setup**: You can test the fully deployed application directly at [**https://social-spark-ai.netlify.app/**](https://social-spark-ai.netlify.app/).

### 📋 Prerequisites
- **Node.js**: `v20.0.0` or higher
- **npm** or **bun** / **yarn** / **pnpm**
- **Google Gemini API Key**: Obtain from [Google AI Studio](https://aistudio.google.com/)

### 🛠️ Step-by-Step Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bikram73/SocialSpark_AI.git
   cd SocialSpark_AI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory:
   ```bash
   cp .env.example .env
   ```
   Add your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_google_gemini_api_key_here
   PORT=3000
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

5. **Build for Production:**
   ```bash
   npm run build
   npm start
   ```

## 🌐 API Documentation

### 1. Generate Full Content Plan
- **Endpoint**: `POST /api/generate`
- **Headers**: `Content-Type: application/json`
- **Request Body**:
  ```json
  {
    "brandName": "FitLife",
    "businessCategory": "Fitness & Wellness",
    "targetAudience": "College Students & Young Professionals",
    "brandVoice": "Friendly and Motivational",
    "contentThemes": "15-Min Workouts, Meal Prep, Mindset",
    "platforms": ["Instagram", "LinkedIn", "X (Twitter)"],
    "primaryGoal": "Increase Community Engagement and Followers",
    "additionalInstructions": "Focus on relatable beginner fitness tips."
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "strategy": "Weekly strategic direction summary...",
    "pillars": ["Educational", "Inspirational", "Promotional", "Community"],
    "tips": [
      "Post Reels on Tuesday mornings for highest organic reach.",
      "Reply to all comments within 30 minutes."
    ],
    "calendar": [
      {
        "day": "Monday",
        "platform": "Instagram",
        "contentType": "Educational Reel",
        "idea": "3 Quick Core Exercises Between Classes",
        "time": "09:00 AM",
        "cta": "Save this post for your next gym session",
        "caption": "No time for the gym? Try these 3 desk-friendly moves! 🏋️‍♂️",
        "hashtags": ["#StudentFitness", "#QuickWorkout", "#FitLife", "#HealthyHabits"],
        "engagementTip": "Ask followers to vote on their favorite move in the comments."
      }
    ]
  }
  ```

---

### 2. Refresh Single Post Caption
- **Endpoint**: `POST /api/refresh-post`
- **Headers**: `Content-Type: application/json`
- **Request Body**:
  ```json
  {
    "day": "Monday",
    "platform": "Instagram",
    "contentType": "Educational Reel",
    "idea": "3 Quick Core Exercises",
    "brandName": "FitLife",
    "brandVoice": "Friendly and Motivational"
  }
  ```
- **Response** (`200 OK`):
  ```json
  {
    "caption": "Ready to energize your Monday? Here is a 3-minute core burner! 🔥",
    "hashtags": ["#FitnessMotivation", "#WorkoutHacks", "#FitLifeCommunity"]
  }
  ```

<a name="limitations"></a>
## ⚠️ Known Limitations & Edge Cases

- 🔑 **API Key Requirement**: Live AI generation requires a valid `GEMINI_API_KEY`. Without a key, the system automatically uses smart deterministic fallbacks.
- ⏳ **Direct Auto-Scheduling**: Does not publish directly to social networks (requires third-party OAuth access tokens and verified Meta / LinkedIn App reviews). Use the 1-click clipboard or Markdown exports to paste into Buffer, Hootsuite, or Notion.
- 📊 **Character Limits**: Multi-paragraph captions generated for Instagram may require trimming if adapted directly into standard 280-character X (Twitter) single tweets without creating a thread.
